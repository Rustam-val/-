# SAVVA — сайт кофейни (Медина, р-н Султана)

Статический сайт: HTML + CSS + JS, без сборки и зависимостей.
Открывается двойным кликом по `index.html` или заливается на любой хостинг
(GitHub Pages, Netlify, обычный сервер) — просто скопировать папку.

## Структура

```
savva/
├── index.html               разметка страницы
├── assets/
│   ├── css/styles.css       весь дизайн и адаптация
│   ├── js/content.js        ← ВСЕ ТЕКСТЫ, МЕНЮ, ЦЕНЫ, КОНТАКТЫ
│   ├── js/app.js            логика (языки, меню, форма)
│   └── img/*.svg            иллюстрации
└── README.md
```

## Что нужно поменять владельцу

Всё редактируется в одном файле — `assets/js/content.js`:

| Что | Где |
|---|---|
| Телефон, e-mail | `SITE.info.phone`, `phoneHref`, `email` |
| Часы работы | `SITE.hours` |
| Блюда, описания, цены | `SITE.menu` |
| Показ цен | `SITE.showPrices` — сейчас `false` |
| Тексты на сайте | объект `I18N` (en / ar) |

### Главная картинка

Сейчас на главной — нарисованная иллюстрация фасада (`assets/img/hero-facade.svg`).
Чтобы поставить настоящее фото:

1. Обрежьте фото так, чтобы остался только фасад (без интерфейса браузера).
2. Сохраните как `assets/img/hero.jpg` (рекомендуется ~2000px по ширине).
3. В `assets/css/styles.css` в блоке `.hero__media` снимите комментарий
   с готовой строки `background-image:url("../img/hero.jpg"), ...`.

### Форма обратной связи

Сейчас форма только проверяет поля и показывает подтверждение.
Чтобы письма реально приходили — подключите Formspree / Google Forms / WhatsApp
в `assets/js/app.js`, функция `initForm()` (место помечено `TODO`).

## Языки

Кнопка в шапке переключает EN ⇄ AR. Арабская версия полностью зеркальная (RTL),
выбор языка сохраняется в браузере. Можно открыть сразу нужный язык:
`index.html?lang=ar`.
